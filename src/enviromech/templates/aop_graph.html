Key Events, dismech nodes and models

Each Key Event of the AOP, the dismech pathophysiology nodes aggregated into it, and the dismech models linked to those nodes. Hover over or select a box to follow its chain. Every link is read from the records; a dashed box is a gap in them.

Select a Key Event, node or model to see what links it.

Key Events are listed in the order the AOP record gives them. The Key Event Relationships between them are not drawn yet: the AOP record names them by id only, and their endpoints will come from Key Event Relationship records.
