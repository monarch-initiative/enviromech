Key Events, methods and dismech nodes

Pathway: each Key Event of the AOP, the dismech pathophysiology nodes aggregated into it, and the dismech models linked to those nodes. Methods: the methods in the centre. Each Key Event joins the EnviroMech assays mapped to it; the assays that are the same method as a dismech model sit in the middle column; dismech's own models join the nodes they are linked to. Only dismech models on a node that a Key Event aggregates are shown. Hover over or select a box to follow its chain. Every link is read from the records; a dashed box is a gap in them.

Key Events are listed in the order the AOP record gives them. The Key Event Relationships between them are not drawn yet: the AOP record names them by id only, and their endpoints will come from Key Event Relationship records.
